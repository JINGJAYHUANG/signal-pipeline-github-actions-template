# Verification Scope

CI verifies Python compatibility, deterministic synthetic data, configuration rejection, selector stability, duplicate suppression, retry behavior, failure-before-state rules, atomic local writes, isolated state-branch behavior, public-safety scanning and pinned GitHub Actions.

CI does **not** prove:
- correctness of a future real dataset;
- profitability or decision quality;
- guaranteed GitHub schedule timing;
- destination availability;
- end-to-end exactly-once delivery;
- regulatory compliance for a particular use case.
